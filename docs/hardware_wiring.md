## Пошаговое подключение

### 1. microSD

```
microSD 32GB → слот на обратной стороне RPi 4B
```
Предварительно прошейте Raspberry Pi OS Lite 64-bit через rpi-imager.

### 2. USB-микрофоны

```
Микрофон 1 (въезд) → USB-порт 2.0 (ближе к краю платы)
Микрофон 2 (выезд) → USB-порт 2.0 (второй)
```

Не используйте USB 3.0 (синие порты) для микрофонов — на некоторых ревизиях RPi 4B USB 3.0 даёт радиопомехи на 2.4 ГГц Wi-Fi, что мешает аудиопотоку.

### 3. Реле-модуль — два контура

**Сигнальный контур** (от RPi к реле):

| RPi пин | Реле пин | Назначение |
|---|---|---|
| Pin 11 (GPIO 17) | IN | Управляющий сигнал |
| Pin 6 (GND) | GND | Общий минус |

**Силовой контур** (питание реле от внешнего БП):

| БП 5В | Реле пин | Назначение |
|---|---|---|
| +5V | VCC | Питание катушки реле |
| GND | GND | Минус питания реле |
| GND | → RPi GND | **Общий минус с RPi — обязательно!** |

**Сухой контакт** (реле → контроллер шлагбаума):

| Реле контакт | Куда | Назначение |
|---|---|---|
| COM | Контроллер шлагбаума: «Общий» | |
| NO | Контроллер шлагбаума: «Открыть» | |

### 4. Внешний БП 5В

```
БП 5В (+) → VCC реле
БП 5В (−) → GND реле → соединить с GND RPi
```

**Только GND общий между RPi и внешним БП.** Не соединяйте 5V RPi и 5V внешнего БП — это вызовет обратный ток и может сжечь RPi.

### 5. Mini Station 2

```
Mini Station → Wi-Fi → тот же роутер, что и RPi
```

Прямого проводного соединения между Mini Station и RPi нет. Связь идёт через облако: RPi → Cloudflare Tunnel → Yandex Cloud → Mini Station.

```
                │   ▼               ▼       ▼

                │ │  Реле-модуль                │
                │ │                             │
                │ │  VCC ◄─── БП 5В (+)        │
                │ │  IN  ◄─── RPi GPIO 17      │
                │ │  GND ◄─── БП 5В (−) + RPi GND
                │ │                             │
                │ │  COM ─────────────────────┐ │
                │ │  NO  ──────────────────┐  │ │
                │ └────────────────────────┘──┘ │

                          │        │

                │ Контроллер             │
                │ шлагбаума              │
                │                        │
                │  «Открыть» ◄── NO      │
                │  «Общий»  ◄── COM      │
                └────────────────────────┘
```

## Проверка перед первым включением

1. **БП RPi** — оригинальный, 5В 3А (для RPi 4B). Не питайте от повербанка — просадки при пике CPU.
2. **Общий GND** — между внешним БП реле и RPi. Без этого реле не сработает, потому что сигнал GPIO не замкнёт цепь.
3. **Нет общего +5V** — никогда не соединяйте +5V внешнего БП и +5V RPi.
4. **NO, не NC** — используйте нормально-разомкнутый контакт. Если перепутаете с NC, шлагбаум будет «открыт» всё время.
5. **GPIO 17** — соответствие пинов по нумерации BCM, не физической. Pin 11 на гребёнке = GPIO 17 в коде.
